# Changelog

## Current source version: Neutral Core 0.1.2

This version number identifies the current source batch. Check the [25 October Neutral Core release page](https://github.com/Ghostzy0/pip-research-replica/releases/tag/research-alpha-2026.10.25) for current publication status, assets, and checksums. The 23 October experimental alpha remains a separate historical release. See [publication history](docs/PUBLICATION.md).

- Neutral Core provides local notebooks, copied PDF/TXT/Markdown sources, source selection, evidence chats, citation navigation, manual notes, and Markdown export. It is an experimental partial workflow recreation, not accepted full NotebookLM/Gemini Notebook fidelity.
- Q8 source-policy history: Notes ownership stays bound to each scene's captured notebook. Its termination ingress used SwiftUI's `presentationPreventsAppTermination(false)` on macOS 15.4+ with Swift 6.1+ and a scoped, restoring AppKit fallback on macOS 14–15.3 and earlier compiler versions. This historical source change is not native acceptance.
- Q9 source gates termination before `super.terminate` can tear down Notes sheets. An early principal-class subclass installs a typed bridge, and guarded one-shot approval covers the native delegate query; direct system queries use `terminateLater` and one reply. Unavailable active Notes sessions and dirty `.close` requests fail closed; pre-model startup can terminate before any Notes session exists. Thirteen Q9 source regressions cover delegate and ingress paths. Q10 local qualification completed 96 cases (93 passed, 3 skipped, 0 failed); both exact Q10 public heads passed hosted CI with the same result on Swift 6.1.2/macOS 15.7.9 arm64.
- On macOS 27.0.1, the final v7 Neutral Plus native slice passed the unchanged station-hours query with fact-bearing 18:00/19:00 citations and conflict detection, saved the 19:00 excerpt, and verified Markdown export and restart persistence. Dirty Cmd-Q Cancel retained the same PID/edit; explicit Notes editor Save followed by clean Cmd-Q and relaunch passed. Q10 did not test Save in the quit-choice alert; the four Q9 prior-package variants' alert-Save evidence is separate. Baseline, Pip Core, and Pip Plus passed final v7 startup/saved-note/clean-quit smoke. The scoped experimental patch is accepted for publication; check the release page above for current asset availability and checksums. The earlier Q7/v4, Q8, and Q9 retrieval observations remain historical to those packages and gates; see [public issue #6](https://github.com/ghostzy0/pip-research/issues/6).
- Optional local Qwen3 1.7B drafting stays off by default and experimental. One bounded synthetic response included citation IDs and named the conflict, but gave a misleading interpretation of source dates. Separately, an opt-in live run passed conflict-plus-persistence and hostile-source cases; absent-fact failed two expectations: asked for public-holiday hours, it returned `The station garden closes at 18:00 on weekdays [1].` without acknowledging that the source only gives weekday hours. It did not explicitly invent holiday hours. One persistence scenario passed; general grounding remains unverified.
