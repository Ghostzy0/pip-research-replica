# Verification and known limits

## Current source status — 25 October 2026

Q10 completed 96 local cases: 93 passed, 3 opt-in live-writer cases skipped, 0 failed. All four products passed local build/package checks. Both exact Q10 public heads passed hosted CI: 96 total, 93 passed, 3 skipped, 0 failed, on Swift 6.1.2/macOS 15.7.9 arm64. On macOS 27.0.1, the final v7 Neutral Plus package passed the unchanged station-hours query with fact-bearing 18:00/19:00 citations and `possibleConflict=true`, saving the 19:00 excerpt, Markdown export and restart persistence. Dirty Cmd-Q Cancel retained the same PID/edit; explicit Notes editor Save followed by clean Cmd-Q and same-store relaunch passed. Q10 did not click Save in the quit-choice alert; the alert-Save proof is separate Q9 prior-package evidence. Baseline, Pip Core, and Pip Plus each passed final v7 startup/saved-note/clean-quit smoke. The scoped experimental patch is accepted for publication; verify package availability and checksums at the [custom release page](https://github.com/Ghostzy0/pip-research/releases/tag/research-alpha-2026.10.25) and [Neutral Core release page](https://github.com/Ghostzy0/pip-research-replica/releases/tag/research-alpha-2026.10.25) after publication. Full parity is not established.

The Q8 source policy kept each Notes scene bound to its captured notebook and allowed one editor owner per notebook. It used SwiftUI's [`presentationPreventsAppTermination(false)`](https://developer.apple.com/documentation/swiftui/view/presentationpreventsapptermination(_:)) on macOS 15.4+ with Swift 6.1+, and a scoped, restoring [AppKit modal-window setting](https://developer.apple.com/documentation/appkit/nswindow/preventsapplicationterminationwhenmodal) on macOS 14–15.3 and earlier compiler versions. That is historical Q8 source behavior; it did not pass the later native quit gate.

Q9 source gates termination ingress before `super.terminate` can tear down Notes sheets. A principal-class subclass installs early at startup and provides a typed bridge. A guarded one-shot approval covers the native delegate query; direct system queries use `terminateLater` and one reply. Unavailable active Notes sessions and dirty `.close` requests fail closed; pre-model startup can terminate before any Notes session exists. Thirteen Q9 source regressions cover delegate and ingress paths. Both exact Q10 public heads now pass hosted CI. The earlier Q9 Neutral Plus retrieval result was a failure: citations and saved excerpt contained headings but omitted the requested times and conflict. The v7 native result below covers that query on the final Neutral Plus package.

## Native observations

A native slice on the exact Q7/v4 Pip package exercised editing and reopening an existing synthetic note and observed Done, Cancel, and Save. The saved note remained after restart, and clean main-window Quit exited normally. Dirty Cmd-Q and enabled app-menu Quit produced no alert; immediate PID checks confirmed the same process remained alive. This is the Q7/v4 dirty-quit result. In a later bounded Q8 native slice, dirty Cmd-Q and menu Quit both exited without a prompt. Reopening offered recovery; restoring it recovered the edited synthetic draft while the saved library remained unchanged. Recovery retained the edit, but neither quit route offered Save/Discard/Cancel, so the Q8 native dirty-quit gate failed.

For all four Q9 prior-package variants, startup and dirty Cmd-Q handling passed: Cancel kept the app open, while Save in the quit alert preserved the edit after restart. Pip Core also passed the app-menu Discard/restart route. On the final v7 Neutral Plus package, the exact unchanged query returned source snippets containing Alder Quay 18:00 and 19:00, with `possibleConflict=true`; citations resolved to their exact source ranges. A new 19:00 excerpt was saved, included as quoted evidence in Markdown export, and persisted after restart. Dirty Cmd-Q Cancel retained the same PID and edit; then the Notes editor's explicit Save button was clicked, clean Cmd-Q exited, and same-store relaunch preserved the note, answer and excerpt. This Q10 slice did not test Save in the quit-choice alert. Baseline, Pip Core, and Pip Plus passed final v7 startup/saved-note/clean-quit smoke. The earlier Q9 failure remains tracked in [public issue #6](https://github.com/ghostzy0/pip-research/issues/6). The scoped experimental patch is accepted for publication; check package availability and checksums at the [custom release page](https://github.com/Ghostzy0/pip-research/releases/tag/research-alpha-2026.10.25) and [Neutral Core release page](https://github.com/Ghostzy0/pip-research-replica/releases/tag/research-alpha-2026.10.25) after publication. Dock Quit and broad accessibility acceptance are not claimed.

One bounded native SIGTERM recovery flow from 23 October restored and saved a synthetic Unicode note. That does not cover ordinary window close, quit coordination, concurrent scenes, failed saves, or general crash recovery.

## Local writer evidence

An earlier bounded synthetic probe with the pinned Qwen3 1.7B returned valid JSON with citation IDs and identified a conflict, but misleadingly interpreted source/revision dates. In a separate opt-in production-model run, conflict-plus-persistence and hostile-source passed. The absent-fact case failed two expectations: asked for public-holiday hours, it returned `The station garden closes at 18:00 on weekdays [1].` without acknowledging that holiday information was absent. It did not explicitly invent a holiday time. This does not establish general grounding or broad product persistence. The writer remains optional, experimental, and off by default. A bounded raw Qwen3.5 0.8B comparison repeated the missing-support failure and was not adopted; no further model comparisons are part of this release review.
