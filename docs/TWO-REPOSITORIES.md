## Shared source and variant identity

Both public repositories contain the shared core and tests. The custom repository owns three executable entry points; the replica repository owns only Neutral Core. Each public repository has its own build profile and manifest. The common implementation does not make the four editions identical: Core omits Plus search/saved-excerpt controls, while Plus editions contain the same additions in neutral or Pip presentation.

The per-notebook Notes owner is bound to the notebook captured by its scene. Q9 gates termination ingress before `super.terminate` can tear down Notes sheets. An early principal-class subclass provides a typed bridge; a guarded one-shot approval covers the native delegate query; direct system queries use `terminateLater` and one reply. Unavailable active Notes sessions and dirty `.close` requests fail closed; pre-model startup can terminate before any Notes session exists. Thirteen Q9 source regressions cover delegate and ingress paths. Q10 completed 96 local cases (93 passed, 3 skipped, 0 failed), and both exact Q10 public heads passed the same 96-case hosted CI on Swift 6.1.2/macOS 15.7.9 arm64. The final v7 Neutral Plus native slice on macOS 27.0.1 verified fact-bearing 18:00/19:00 citations, conflict detection, saved excerpt/export, restart persistence, dirty Cmd-Q Cancel, and explicit editor Save followed by clean Quit/relaunch. This did not test alert Save. Baseline, Pip Core, and Pip Plus passed final v7 startup/saved-note/clean-quit smoke. The Q9 Neutral Plus retrieval failure is historical and tracked in [public issue #6](https://github.com/ghostzy0/pip-research/issues/6). The scoped experimental patch is accepted for publication; verify package availability and checksums at the linked 25 October release pages.

## Evidence and limits

Historical qualification 4 on 24 October completed 80 cases: 77 passed, 3 opt-in live-writer cases skipped, 0 failures. All four release products were built, signature-verified, and scanned for private-path strings. Separately, an opt-in run passed conflict-plus-persistence and hostile-source cases; absent-fact failed two expectations: asked for public-holiday hours, it returned `The station garden closes at 18:00 on weekdays [1].` without acknowledging that the source only gives weekday hours. It did not explicitly invent holiday hours. Those earlier results do not establish current Q9 native UI acceptance, accessibility, a clean-clone review, or publication.

Q8's later native slice found dirty Cmd-Q and menu Quit both exited without prompting. Recovery restored the edited synthetic draft while the saved library remained unchanged, but neither route offered Save/Discard/Cancel; the Q8 native gate failed. All four Q9 prior-package variants later passed bounded startup and dirty Cmd-Q Cancel/alert-Save/restart; Pip Core also passed menu Discard/restart. Q9 Neutral Plus retrieval nevertheless failed because citations/excerpts omitted the requested times. Q10 local qualification and exact-head hosted CI passed, and the v7 Neutral Plus native slice fixed that retrieval case. Baseline, Pip Core, and Pip Plus passed final v7 startup/saved-note/clean-quit smoke. The scoped experimental patch is accepted for publication; anonymous download/checksum verification follows publication.

One bounded synthetic Qwen3 1.7B response took 2.739 seconds and included the required citation IDs and stated that the two source values conflict. It also misleadingly interpreted source/revision dates as dates for the values. Separately, the opt-in production-model run passed the conflict-plus-persistence and hostile-source cases.
