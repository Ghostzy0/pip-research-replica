## Current qualification evidence

Q10 completed 96 local cases (93 passed, 3 opt-in live-writer skips, 0 failed), with all four products passing local build/package checks. Both exact Q10 public heads passed hosted CI: 96 total, 93 passed, 3 skipped, 0 failed, on Swift 6.1.2/macOS 15.7.9 arm64. On macOS 27.0.1, the final v7 Neutral Plus package passed fact-bearing retrieval of 18:00 and 19:00 with `possibleConflict=true`, exact excerpt save/export and restart persistence. Dirty Cmd-Q Cancel retained the same PID/edit; explicit Notes editor Save followed by clean Cmd-Q and same-store relaunch passed. Q10 did not test Save in the quit-choice alert; separate Q9 prior-package evidence covers alert Save across four variants. Baseline, Pip Core, and Pip Plus each passed final v7 startup/saved-note/clean-quit smoke. The scoped experimental patch is accepted for publication; full reference parity, accessibility, platform coverage, and general writer grounding are not implied. Check current release status and checksums at the linked 25 October pages.

One bounded synthetic Qwen3 1.7B output returned valid JSON with the requested citation IDs and named the disagreement between two passages. It completed in 2.739 seconds but misleadingly interpreted source/revision dates as dates for the source values. Separately, the opt-in production-model run passed the conflict-plus-persistence case and the hostile-source case. The absent-fact case failed two expectations; asked for public-holiday hours, it returned `The station garden closes at 18:00 on weekdays [1].` without acknowledging the source had weekday-hours information only. One synthetic persistence scenario passed, but general grounding and broader product persistence remain unverified. The writer remains experimental and disabled by default.

The Q8 Notes source preserved each scene's captured target and allowed one editor owner per notebook. Its termination-ingress policy used SwiftUI's [`presentationPreventsAppTermination(false)`](https://developer.apple.com/documentation/swiftui/view/presentationpreventsapptermination(_:)) on macOS 15.4+ with Swift 6.1+, and a scoped, restoring [AppKit modal-window property](https://developer.apple.com/documentation/appkit/nswindow/preventsapplicationterminationwhenmodal) on macOS 14–15.3 and earlier compiler versions. This describes the historical Q8 source policy, not native acceptance.

Q9 source gates termination ingress before `super.terminate` can tear down Notes sheets. A principal-class subclass installs early at startup and provides a typed bridge; a guarded one-shot approval covers the native delegate query; direct system queries use `terminateLater` and one reply. Unavailable active Notes sessions and dirty `.close` requests fail closed; pre-model startup can terminate before any Notes session exists. Thirteen Q9 source regressions cover delegate and ingress paths. The earlier Q9 Neutral Plus package's answer and excerpt cited only headings, omitted 18:00/19:00 and reported no conflict; this historical failure remains in [public issue #6](https://github.com/ghostzy0/pip-research/issues/6). The final v7 Neutral Plus native pass addresses that retrieval case only.

On the exact Q7/v4 Pip package, editing and reopening an existing synthetic note and Done, Cancel, and Save worked; saved content persisted after restart, and clean main-window Quit exited normally. Dirty Cmd-Q and enabled menu Quit produced no alert, and immediate PID checks confirmed the same process remained alive. This is the Q7/v4 dirty-quit result. In a later bounded Q8 native slice, dirty Cmd-Q and menu Quit both exited without a prompt. Reopening offered recovery; restoring it recovered the edited synthetic draft while the saved library remained unchanged. Recovery preserved the edit, but no Save/Discard/Cancel choice appeared during either quit route, so the Q8 native dirty-quit gate failed.

For all four Q9 packaged variants, startup and dirty Cmd-Q handling passed: Cancel kept the app open, while Save in the quit alert preserved the edit after restart. Pip Core also passed the app-menu Discard and restart route. These are separate prior-package component results, not the v7 Neutral Plus alert-Save route. The v7 Neutral Plus slice passed fact-bearing retrieval, excerpt save/export and restart on macOS 27.0.1. Dirty Cmd-Q Cancel kept the same PID/edit; an explicit Notes editor Save then allowed a clean quit and same-store relaunch. Baseline, Pip Core, and Pip Plus each passed final v7 startup/saved-note/clean-quit smoke. Literal Dock Quit and broader native/accessibility acceptance remain unverified.
