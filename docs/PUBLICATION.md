## Current qualification evidence

Qualification 10 completed 96 cases: 93 passed, 3 opt-in live-writer cases skipped, 0 failed. All four products passed local build/package checks. Qualification 9 and both exact Q9 public heads also passed their 91-case checks (88 passed, 3 skipped, 0 failed). Q10 hosted CI and the v7 packaged native checks remain pending; these results do not establish release approval or full reference parity. Public-export review and native/runtime evidence remain separate gates; no new release is announced here.

One bounded synthetic Qwen3 1.7B output returned valid JSON with the requested citation IDs and named the disagreement between two passages. It completed in 2.739 seconds but misleadingly interpreted source/revision dates as dates for the source values. Separately, the opt-in production-model run passed the conflict-plus-persistence case and the hostile-source case. The absent-fact case failed two expectations; asked for public-holiday hours, it returned `The station garden closes at 18:00 on weekdays [1].` without acknowledging the source had weekday-hours information only. One synthetic persistence scenario passed, but general grounding and broader product persistence remain unverified. The writer remains experimental and disabled by default.

The Q8 Notes source preserved each scene's captured target and allowed one editor owner per notebook. Its termination-ingress policy used SwiftUI's [`presentationPreventsAppTermination(false)`](https://developer.apple.com/documentation/swiftui/view/presentationpreventsapptermination(_:)) on macOS 15.4+ with Swift 6.1+, and a scoped, restoring [AppKit modal-window property](https://developer.apple.com/documentation/appkit/nswindow/preventsapplicationterminationwhenmodal) on macOS 14–15.3 and earlier compiler versions. This describes the historical Q8 source policy, not native acceptance.

Q9 source gates termination ingress before `super.terminate` can tear down Notes sheets. A principal-class subclass installs early at startup and provides a typed bridge; a guarded one-shot approval covers the native delegate query; direct system queries use `terminateLater` and one reply. Unavailable active Notes sessions and dirty `.close` requests fail closed; pre-model startup can terminate before any Notes session exists. Thirteen Q9 source regressions cover delegate and ingress paths. Both exact Q9 public heads passed hosted CI. Q10 local qualification passed; hosted Q10 CI and v7 native checks remain pending.

On the exact Q7/v4 Pip package, editing and reopening an existing synthetic note and Done, Cancel, and Save worked; saved content persisted after restart, and clean main-window Quit exited normally. Dirty Cmd-Q and enabled menu Quit produced no alert, and immediate PID checks confirmed the same process remained alive. This is the Q7/v4 dirty-quit result. In a later bounded Q8 native slice, dirty Cmd-Q and menu Quit both exited without a prompt. Reopening offered recovery; restoring it recovered the edited synthetic draft while the saved library remained unchanged. Recovery preserved the edit, but no Save/Discard/Cancel choice appeared during either quit route, so the Q8 native dirty-quit gate failed.

For all four Q9 packaged variants, startup and dirty Cmd-Q handling passed: Cancel kept the app open, while Save preserved the edit after restart. Pip Core also passed the app-menu Discard and restart route. Neutral Plus editing/export mechanics passed, but fact-bearing retrieval failed: its answer and excerpt cited title spans 0:45 and 0:44 while omitting 18:00 and 19:00, even after the full originals were opened. This shared retrieval issue is tracked in [public issue #6](https://github.com/ghostzy0/pip-research/issues/6). Q10 Core retrieval qualification passed locally, but hosted Q10 CI and v7 native checks are pending. The overall release remains on hold.
