# Security and privacy

All four variants run locally with platform frameworks. Evidence mode has no network requests, telemetry, provider credentials, hosted runtime or automatic model downloads. Optional local drafting uses a fixed loopback URLSession client: after explicit opt-in it checks the installed Ollama model manifest, then sends the question and selected evidence passages only to 127.0.0.1:11434. Redirects, authentication, cookies and configured proxies are blocked. There is no remote fallback; source text is disclosed to that local process when drafting is requested. Imported source text is inert data: it cannot run tools, open URLs or cause actions. Evidence mode quotes retrieved passages; it does not establish that the quoted claims are true or answer the question. Check citations and original context.

Sources are copied into the edition's Application Support folder with a SHA-256 identity. Notebooks, extracted text, saved chats, manual notes and citation excerpts are stored locally as readable JSON, not encrypted by this app. Unsaved manual-note editor recovery copies may also appear as readable JSON in `.note-drafts/` under that same folder. Your macOS account and disk protections govern access. Back up the whole app-support folder while the app is closed; do not sync a live library between processes/machines.

Pip edition: `~/Library/Application Support/Pip Research`. Baseline: `~/Library/Application Support/Research Baseline`. Enhanced variants append ` Enhanced` to those folder names and use distinct bundle identifiers. `Originals/` contains copied source files; `library.json` contains notebooks, extracted passages, chat evidence, manual notes and enhanced saved excerpts. Manual notes are available in all four variants and may contain arbitrary user-authored text. `.note-drafts/` holds pending editor recovery copies, scoped by notebook. Source removal invalidates navigation but retains historical quoted evidence in chats and enhanced saved excerpts. Removing an excerpt removes its saved quote, label and annotation from that collection, while the earlier chat and source stay. Remove the notebook to remove its chats, notes and saved excerpts as well. Exports and external originals are separate owner-managed files. A cleanup failure is shown and must not be treated as secure erasure. Storage is not a forensic erasure system.

Imports are bounded to 30 MB, 2,000,000 extracted UTF-16 units and 500 PDF pages per source. Scanned pages without selectable text require external OCR; no OCR service/upload is used. File types/encoding/corrupt/oversize inputs fail locally. App-owned original hashes are checked when opening citations/reindexing; modified copies may require restoring from backup.

This is experimental software. Do not use excerpts as an authoritative medical, legal or financial answer. Report reproducible security issues through the repository's Security tab if private reporting is available, or open a minimal issue without confidential documents. Do not upload tokens, source text, personal files, full app-support folders or raw logs containing private paths. No response-time SLA is promised.
